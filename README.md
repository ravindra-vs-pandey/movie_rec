🎬 CineVault

A full-stack movie web application that allows users to search movies, view details, and manage a personalized wishlist with ratings and notes.

🚀 Features
🔍 Search movies using OMDb API
🎬 View detailed movie information
❤️ Add / Remove movies from wishlist
⭐ Rate movies
💬 Add personal notes
🔐 Secure authentication (JWT + bcrypt)
📊 Dynamic wishlist count
🎥 Watch trailer (YouTube redirect)
🛠️ Tech Stack
Frontend
React (Vite)
Axios
CSS (Netflix-style UI)
Backend
Node.js
Express.js
MongoDB Atlas
Mongoose
Authentication
JWT (JSON Web Token)
bcrypt (Password hashing)
